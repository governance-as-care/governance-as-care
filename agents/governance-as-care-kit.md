# The kit's own card

Every registry should start with an honest first entry, and this one is ours:
the kit, governed by the kit.

**What it does:** Provides an agent card schema, two fill-in forms, a field
guide, and a heartbeat script — so that any team, from a solo builder to a
hospital, can inventory the agents they run and answer for each one.

**What it must never do:** Grow a login, a price, a dependency, or a vendor.
The day it needs any of those, its charter is drifting, and this card says so
in writing.
